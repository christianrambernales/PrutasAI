UI/UX Improvement Plan Compliance

This v2 prototype satisfies all findings from docs/interactive-prototype-ui-ux-improvement-plan.md:

  • P0 Truthful Capabilities: Clear distinction between offline no-model state and explicit sample diagnoses. Removed unsupported claims like "Certified" or "Prescription".
  • P1 Automatic Fruit Detection: Camera and gallery pipeline automatically detects the fruit crop (Mango, Banana, Papaya) without requiring an intermediate confirmation screen.
  • P1 Settings-Only Language Selection: Language preferences are accessed exclusively in Settings; global header and home cards remain dedicated to core workflow.
  • P1 High-Contrast Distinct Navigation: Bottom navigation bar features crisp line icons, active forest green highlights with pill backgrounds, and a pure white camera icon on the center FAB.
  • P1 Missing Auth Suite: Integrated Log In, Create Account, Email Confirmation, and Password Recovery with guest offline continuation.
  • P1 Monitoring Structure: Separated monitoring sessions list from checkpoint logging; eliminated preselected outcomes.
  • P1 Accessibility & WCAG Contrast: High-contrast color tokens (>4.5:1), 48px touch targets, SVG icons instead of emojis, accessible form labels, and focus rings.
  • P1 Full Bilingual Equivalence: All 19 screens and navigation states seamlessly switch between Tagalog (Filipino) and English via Settings.
